`feat(spell): 支持武器魔力石赋予（mode2）与适用确认（mode4），补全巨型深渊数据`

## 说明

源仓库 `641927456/els-server-collab` 的 `main`（`932a5e1`）已包含此前合并的十项修复，因此本 PR 的**实际代码 diff 只有今天的魔力石赋予**；下面把前置改动也列出，便于维护者核对整体范围。

## 前置已合并（源 main 已包含，不在本 PR diff）

1. **原力技能**：528 条原力书英文目录、主动原力槽、装备/卸下与冷登录投影。
2. **消耗品**：HP/MP、非持久 buff/变身、空效果+关联 buff；副本可用、城镇禁用。
3. **地区任务**：99 级角色自动接取地区入口任务；未注册 NPC 对话必回空包。
4. **共鸣**：99 级共鸣解锁任务自动接取。
5. **GM 发放**：饰品/电路按客户端记录推导背包组；T 电路链接属性；邮件与卷轴队列。
6. **装备**：`136182` 三鉴定槽；装备中可属性变换/炼制。
7. **商店**：本地商品配置与数量处理。
8. **分解**：电路材料/时装按价格下限产出魔法结晶。
9. **库存/时装**：GM 模板启动注册、时装/冰装页默认开启。
10. **会话接线**：原力槽分发、地区/共鸣 tick、衣橱重发、`0x225/0x226` 回包、GM 邮件 tick。

## 风险与后续

- 深渊选项 ID 来自旧客户端已解析的 `OptionItemData`；当前客户端若缺少对应显示文本，可能出现空白/`???`，需实机确认。
- mode2 目前是“立即提交”，mode4 仅回当前状态；若客户端要求严格两段式（预览→提交），后续可增加 pending 状态。
